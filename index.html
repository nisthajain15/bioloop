            Why BSF?

            Black Soldier Fly larvae (Hermetia illucens) consume a wide range of kitchen waste quickly, convert it into larval biomass rich in protein and fat, and leave behind a nutrient-rich frass that works as organic fertilizer.

            The BioPod

            A compact, solar-backed BSF unit with ventilation, mesh separation and a drainage outlet. Sensors (temperature, humidity, moisture) feed this dashboard — see IoT Monitoring.

            Good operating practice

            Shred waste, feed in thin layers, keep substrate moist but not waterlogged, keep temperature in the warm range, and avoid excess oil or liquids. Ask BioBot for tips tuned to your numbers.

            IoT monitoring

            Temperature, humidity and substrate moisture of the BioPod, with configurable thresholds and alerts.

            ESP32 / hardware connection

            Ready for future integration — the dashboard polls a JSON endpoint on your local network

            Expected response: {"temperature":30.2,"humidity":64,"moisture":66}. The device must send the header Access-Control-Allow-Origin: *.

            Example ESP32 sketch
            #include <WiFi.h>
#include <WebServer.h>
#include <DHT.h>
DHT dht(4, DHT22);          // temp + humidity
const int MOIST_PIN = 34;   // analog moisture probe
WebServer server(80);

void handleSensors() {
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  int raw = analogRead(MOIST_PIN);
  float m = map(raw, 3200, 1200, 0, 100); // calibrate!
  String j = "{\"temperature\":" + String(t,1) +
             ",\"humidity\":" + String(h,0) +
             ",\"moisture\":" + String(m,0) + "}";
  server.sendHeader("Access-Control-Allow-Origin", "*");
  server.send(200, "application/json", j);
}
void setup() {
  dht.begin();
  WiFi.begin("SSID", "PASSWORD");
  while (WiFi.status() != WL_CONNECTED) delay(300);
  server.on("/sensors", handleSensors);
  server.begin();
}
void loop() { server.handleClient(); }
